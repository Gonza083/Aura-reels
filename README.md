# Aura Reels

Videos de obra → reels profesionales con la marca de Aura Hogar.

## Uso (cuando esté construido)
1. Subir el video a **Google Drive → `Reels/entrada`** (desde el celular o la PC).
2. En la PC de escritorio, abrir Claude Code en esta carpeta y decir: **"procesá los videos de entrada"**.
3. Aprobar el resumen del plan de edición.
4. El reel, la portada y el texto para la publicación aparecen en **Drive → `Reels/salida`**.

## Estado
Plan armado el 2026-11-10 y actualizado el 2026-11-12 (render con Hyperframes). Pendiente de ejecución en la PC de escritorio → ver `PLAN.md`.

## Puesta en marcha en otra PC
1. Instalar **Google Drive para escritorio** (google.com/drive/download) e iniciar sesión.
2. Crear en Drive la carpeta `Reels` con `entrada` y `salida` adentro.
3. Clonar y abrir Claude:
```bash
git clone https://github.com/Gonza083/Aura-reels.git
cd Aura-reels
claude
```
4. Decirle a Claude: *"Leé CLAUDE.md y PLAN.md y arrancá con los hitos de esta noche (N1 a N3)."*
